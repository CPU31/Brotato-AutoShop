# 版本记录

## 1.2.0 · 2026-10-30

- 修复搜索输入 WASD 等字符与 UI 导航绑定冲突；合并连续输入时的图标刷新。
- 白名单面板新增“金币不够刷新时自动出发”开关，默认关闭并持久化。
- 仅实际付不起刷新费时，通过游戏原生出发入口进入下一波，支持演练、人工打断及临行重查。
- 7 项搜索输入检查、15 项执行层检查、22 项决策检查、10 项奖励检查及加载器隔离检查通过；最终游戏测试由用户进行。


## 1.1.0 · 2026-10-30

- “发现道具”复用白名单：白名单领取、其他回收；奖励空白名单全部回收。
- 使用原生领取／回收入口，支持连续奖励、演练、手动打断及重复调用去重。
- 不处理升级属性选择；保持单人模式限制。
- 新增 10 项奖励自动检查；商店 31 项回归及加载器隔离检查通过。
- 最终实机测试由用户完成。


## 1.0.0 · 2026-10-30

- 五件初始道具 ID 由本机基础包／DLC 资源核对。
- 自动购买白名单普通道具，并按预算刷新；原生 API 负责扣款及入包。
- F8 图标白名单编辑器，支持搜索、已选过滤、增删、保存／取消、重启持久化。
- F7 手动执行、F6 停止，鼠标／键盘／手柄操作打断自动流程。
- 总开关、演练、四项预算、原生 HP 货币与最低生命保护。
- 每动作间隔 0.5 秒；连续免费刷新保护、忙碌重试与动作确认。
- 配置非法值回退；空白名单和全部失效 ID 零动作。
- 单独及时写盘的 autoshop.log，并记录候选判定和停止原因。
- 22 项决策／配置检查和 9 项执行流程检查通过。
