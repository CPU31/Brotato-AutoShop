# Brotato AutoShop · 自动商店

适用于《Brotato / 土豆兄弟》的单人游戏内 Mod。自动购买白名单道具、刷新商店、处理战后箱子奖励，并通过图标界面管理白名单。

当前版本 **1.2.0**，Mod ID：`tang-AutoShop`。

## 功能

- **自动商店**：先购买买得起的白名单普通道具，再刷新；每次操作后重新读取实际价格和余额。
- **图标白名单**：点击图标加入／移除，支持中文名称与内部 ID 搜索、只看已选、物品效果悬停说明、保存／取消及重启保留。
- **预算**：保留金币、单件价格、刷新次数、刷新单价四项限制；上限填 `-1` 表示不限。
- **战后发现道具**：白名单内自动领取，其他自动回收；不处理升级属性选择。
- **可选自动出发**：实际金币不足以刷新时进入下一波，默认关闭。
- **演练与接管**：演练只记录决策；键盘、鼠标或手柄操作可打断自动流程。

不购买武器、消耗品和箱子，不自动战斗、合成、出售装备或选择升级属性。战斗中隐藏设置入口。

## 兼容范围

开发核对环境为 Brotato **1.1.15.4**、Godot **3.7.dev.custom_build**、内置 ModLoader **6.3.0**，含 **Abyssal Terrors** DLC。

基础商店行为曾在同时启用 Mod Options、bigmap、EasyToGet-FishHook、GAFF-GMO3、yshi50-Hextech 的环境下验证。没有限制单人角色名单，但未穷举所有角色、DLC 和其他 Mod 的特殊机制。**多人模式未接入。**游戏版本变化后可能需要重新核对接口。

## 下载与安装

1. 从 [Releases](https://github.com/CPU31/Brotato-AutoShop/releases) 下载 `tang-AutoShop-1.2.0.zip`。
2. 完全退出游戏，移走旧版 AutoShop ZIP，避免同 ID 多版本同时加载。
3. Steam 版当前验证过的安装方式：已订阅并启用 **Mod Options** 时，将整个 ZIP **不解压**，放在它的创意工坊内容目录中，与原有 `Mod Options.zip` 并排：

   ```text
   <Steam 库>/steamapps/workshop/content/1942280/3598984651/
   ```

4. 通过 Steam 启动游戏，按 **F8** 打开设置。

这是已订阅目录的本地加载方式，并不代表本项目已上传创意工坊。Steam 更新或取消订阅可能清理附加 ZIP，届时需要重新放入。不同平台或加载器设置需使用对应的 ModLoader 安装方式。

不要把 GitHub 的整份源码压缩包当成可安装 Mod；安装包内应是：

```text
mods-unpacked/tang-AutoShop/manifest.json
mods-unpacked/tang-AutoShop/mod_main.gd
```

卸载时退出游戏并移走新增的 AutoShop ZIP 即可，保留其他 Mod 文件。游戏原文件无需替换或还原。

## 使用

| 操作 | 功能 |
|---|---|
| **F8**／屏幕上方“自动商店”按钮 | 在主菜单或商店打开设置 |
| 点击物品图标 | 加入白名单，再点移除 |
| 搜索框 | 搜索中文名或物品 ID |
| 悬停物品图标 | 查看游戏自身的效果说明 |
| 保存并关闭 | 保存本次修改；取消关闭则放弃修改 |
| **F7** | 在当前商店手动执行自动流程 |
| **F6** | 停止自动操作 |

进入商店后约等待 0.2 秒启动，每次购买／刷新间隔 0.5 秒。打开设置会暂停游戏并停止当前自动流程，关闭后不会立即继续花钱；下次进商店或按 F7 才重新执行。

初始白名单为 **蜂蜜、导弹、被腐蚀的碎片、Grind的魔法绿叶、镜子**。它们只作为首次初始化预设，之后可自由增删。目录只列可进入普通道具池的条目，过滤角色部件等内部对象；目录中的物品仍不一定在当前角色的商店池中。

## 重要规则

| 场景 | 行为 |
|---|---|
| 商店白名单为空 | 不购买、不刷新，也不自动出发 |
| 战后发现道具时白名单为空 | **全部自动回收** |
| 商店目标买不起 | 允许刷新掉它，继续寻找其他买得起的目标 |
| 关闭“自动商店与奖励”总开关 | 商店及发现道具界面均手动处理 |
| 开启演练 | 只记录决策，不购买、不刷新、不领取、不回收、不出发 |
| 人工按键／点击／手柄输入 | 中止当前自动操作，交还控制权 |

“金币不够刷新时自动出发”默认关闭，需要在 F8 设置中开启并保存。仅实际余额不足以支付刷新费用时触发；预算限制、手动停止、异常、空白名单和免费刷新不会误触发。出发前再等待半秒并重新核对状态。

默认不额外留金币，三个价格／次数上限均为 `-1`。HP 商店使用原生货币接口并至少保留 1 点最大生命。连续 100 次免费刷新会触发防无限执行保护，正常付费刷新没有隐藏次数上限。

## 配置与日志

Windows 当前配置：`%APPDATA%/Brotato/configs/tang-AutoShop/autoshop.json`。

优先通过 F8 界面修改。加载器的 `default.json` 是默认模板；源码中的 `config_defaults.json` 是参考副本，直接编辑它不会立即修改现有配置。

| key | 默认 | 说明 |
|---|---|---|
| enabled | true | 商店与奖励总开关 |
| dry_run | false | 演练 |
| whitelist | 首次初始化五件预设 | 内部 ID 数组；主动清空后重启仍为空 |
| keep_gold | 0 | 最少保留材料数 |
| max_item_price | -1 | 单件价格上限 |
| max_rerolls | -1 | 一次自动流程的刷新次数上限 |
| max_reroll_cost | -1 | 刷新单价上限 |
| auto_depart | false | 金币不足以刷新时自动出发 |
| buy_weapons / buy_consumables | false | 当前版本固定禁止 |
| confirm_delay | 0.2 | 启动等待，秒 |
| verbose | true | 详细判定日志 |

`preset_initialized` 为内部初始化标记，不建议手动修改。

日志位于 `%APPDATA%/Brotato/logs/`，优先查看 **autoshop.log**。前缀为 `[AutoShop]`，演练带 `[DRY]`。`CANDIDATE` 记录判定原因，`BUY_CONFIRMED` 表示原生购买完成，`REWARD_ACTION` 表示领取／回收决定，`AUTO_DEPART` 表示自动出发，`STOP` 记录停止原因。

## 源码与打包

`mods-unpacked/tang-AutoShop/` 是 Mod 源码，包含配置、纯决策、分帧执行、商店快照、奖励处理、脚本扩展及界面模块。

使用 Python 3 标准库构建安装包，不需要下载游戏资源：

```bash
python tools/package.py
```

生成文件位于 `dist/`。本项目通过 ModLoader 运行时扩展及原生游戏入口接入；仓库不包含游戏原始资源、反编译源码、游戏运行程序或存档。
